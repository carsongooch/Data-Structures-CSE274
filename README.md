# Data Structures — CSE 274

A collection of coursework, implementations, and programming exercises completed for CSE274: Data Structures at Miami University.

This repository contains Java implementations and exercises covering fundamental data structures, algorithms, object-oriented programming, recursion, and data processing.

## Topics & Concepts

- Arrays and dynamic arrays
- Linked lists and linked nodes
- Stacks and queues
- Deques
- Sets and maps
- Hash tables
- Binary trees and binary search trees
- Heaps
- Recursion and tree traversal
- Generics and interfaces
- JUnit testing
- Algorithmic problem solving

## Repository Structure

### Class Work

Smaller implementations and exercises used to practice individual data structures and algorithms.

- **Fixed Array Set** — Array-based set implementation
- **HashSet Implementation** — Hash table and collision handling
- **Heap Lab** — Heap implementation and testing
- **Interfaces and Generics** — Generic collection interfaces and implementations
- **IntroStacks** — Stack implementation and fundamentals
- **MapIntro** — Map and key-value data structures
- **Node Learning** — Linked-node structures and traversal
- **Stack Lab** — Stack-based problem solving
- **Tree Intro** — Binary tree fundamentals
- **Tree Lab** — Binary search tree set implementation
- **Tree Practice** — Additional tree exercises 
- **TreeLab2** — Binary search tree set implementation
- **Resizable Array Homework** — Fraction and FractionSet implementations

## Selected Work

### Linked Data Structures

Implemented linked-node structures including linked lists, and linked sets, working with node references, insertion, removal, traversal, and collection operations.

### Hash Tables & Sets

Implemented set functionality using array-based and hash-based approaches, including operations such as insertion, removal, searching, and membership checking.

### Heaps

Worked with heap-based data structures and their associated operations and testing.

### Generics & Interfaces

Implemented generic collection types and interfaces to support reusable data structures across different object types.

Several implementations include dedicated tester classes and JUnit tests to verify data-structure behavior and edge cases.
